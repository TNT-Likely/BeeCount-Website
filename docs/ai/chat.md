# AI 对话

智能财务助手，用自然语言与 AI 交流。

## 进入对话

1. 在「明细」页右上角点击 AI 图标
2. 或长按 App 图标 →「AI 小助手」

## 对话示例

### 记账

```
帮我记一笔，今天中午吃饭花了 45 块
```

3.2.3 起,AI 对话也支持**一句话识别多笔交易**:

```
帮我记下，今天打车 30，晚饭 45，奶茶 18
```

写入会遵循本机工具权限设置；成功后显示记账卡片，可查看记录、修改或撤销。示例只是输入方式，不代表固定的回复文案。

### 查询

```
用户：这个月我花了多少钱？
AI：本月您的支出情况：
    - 总支出：3,256 元
    - 餐饮：1,200 元（36.8%）
    - 交通：450 元（13.8%）
    - ...
```

### 分析

```
用户：我的消费有什么问题吗？
AI：根据您的记账数据分析：
    1. 餐饮支出占比较高，建议...
    2. 娱乐消费集中在周末...
```

### Agent 对话体验

AI 助手会在本地按需调用账本工具：

- 查询总额、分类、标签或账户分布时，直接使用本地数据聚合，不受明细条数限制。
- 工具执行过程会在对话中实时展示，完成后再给出答案或记账卡片。
- 记忆和工具权限由本机管理；涉及写入账本的操作会遵循权限设置。
- 对话保留本地历史，支持连续追问；长对话会自动整理发送给模型的上下文，不删除界面记录。

## 3.8.3 对话体验

### 通栏阅读与流式回答

回答采用通栏布局，减少头像和操作栏对正文宽度的占用。兼容的模型会逐步输出回答；服务商不支持流式工具调用时可能使用非流式兼容路径，不能保证所有模型都逐字显示。

处理状态与工具调用过程集中展示，可展开查看安全的执行摘要；这不是模型完整内部推理。运行中可停止，不必等待全部生成完成。

### 回答后的「继续了解」

最新有效回答下方提供独立的主题浅色区域，默认显示两条问题，点击「换一组」浏览其他候选。

- 成功查询后，按实际时间范围、分类和工具结果选择相关追问。
- 同时保留支出总结、分类占比、预算建议等完整分析问题；点击后仍由同一助手查询，不预先拼接账本数据。
- 问题轮换在本地完成，不额外请求模型；分析推荐采用只读限制，不自动修改预算或账单。
- 查询失败、取消等情况不会生成假装有数据依据的新追问。

### 长对话自动整理

当历史长度或字符预算达到阈值时，助手会使用「旧历史摘要 + 最近原文」继续对话。触发依据是历史条数和字符预算，不是服务商的精确 token 计数；当前没有独立的上下文用量仪表或摘要过程面板。

摘要缓存按会话和账本隔离，编辑或删除历史后会失效；摘要失败时使用有界历史继续。摘要可能遗漏细节，不作为当前金额事实，也不会自动保存成长期记忆。需要最新账本数字时，应让助手重新查询。

### 适合询问什么

例如「今年各月餐饮支出是多少」「本月分类占比」「和上个月相比呢」。总额与分组由本地查询工具计算，模型负责理解问题和解释结果。模型仍可能理解错范围，重要数字请与账本统计核对。

异常支出分析仅能解释实际取得的数据；预算建议不自动设置预算，也不是对未来支出的保证。

## 模型配置与数据边界

账本查询需要文本模型支持原生工具调用。普通文本测试成功，不一定表示账本工具可用；请在 [AI 设置](./overview.md) 的服务商管理中测试文本模型。测试失败时可查看服务商返回的状态码、错误码和消息，检查地址、Key、额度或模型配置。

工具在本机执行，但用户问题、必要历史和工具结果会发送给所配置的模型服务商，不是所有 AI 处理都离线完成。自动摘要也可能产生模型调用；费用与可用能力取决于服务商。请勿在对话中输入不必要的敏感信息。

## 消息操作

长按对话中的消息，可以进行以下操作：

- **复制** - 复制消息内容
- **删除** - 删除单条消息

## 自定义提示词

在 AI 设置中可以自定义提示词，让 AI 更符合你的使用习惯。

## Web 端文字记账

登录 [BeeCount Cloud](../cloud-sync/beecount-cloud.md) Web 端后,桌面浏览器可以**直接粘贴文字**给 AI 转交易:

1. 任意页面按 **⌘K / Ctrl+K** 打开命令面板
2. **粘贴一段文字** — 微信账单文本块、Excel 选区、自然语言描述如「昨天打车 30 + 午饭 25」
3. 默认动作切到「AI 记账(文字)」→ Enter
4. 弹出 N 笔交易草稿,逐笔确认 → 批量保存

服务器端用 chat LLM(智谱 GLM-4-Flash / DeepSeek 等,需在 [AI 配置](./overview.md#web-端-ai-配置) 里绑定)解析。

### Web 端 ⌘K 也能问 AI 文档

输入 `?xxx` 前缀 → 命令面板默认动作切到「问 AI:xxx」→ Enter → 弹出 RAG 检索 + LLM 回答的对话窗。底层用 BeeCount-Website 文档站索引,问"怎么开启二次验证 / Docker 部署 / 标签怎么用"等都能从官方文档拿答案。
