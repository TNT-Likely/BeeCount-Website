# 统计分析

蜜蜂记账提供丰富的统计图表，帮助你了解自己的收支情况。

![统计页面](/img/preview/v4/zh/light/02-analytics.png)

## 收支趋势

App 4.0 的洞察页通过 Tab 切换支出、收入和结余视角。趋势柱状图提供平均线，点击柱子查看对应日期或月份的金额。

## 分类占比

独立卡片展示分类占比和排行，使用统一的主题强调色；结余视角展示收支构成。

## 分类排行

列表形式展示分类排行，点击可查看该分类下的所有交易。

## 时间筛选

通过顶部「月 / 年 / 全部」Tab 选择范围，再用日期入口切换具体年月。

## 首页汇总布局

首页默认保留完整汇总。点击首页右上角「更多」，选择「切换为紧凑汇总」可将预算进度与收支放在同一卡片；再次选择「切换为完整汇总」恢复原布局，选择会保存。

## Web 端统计

登录 [BeeCount Cloud](../cloud-sync/beecount-cloud.md) Web 端后,桌面浏览器有更强的可视化能力:

- **首页 Hero** — 当月总览 + 收支曲线 + 资产构成饼图 + Top 分类 / 标签 / 账户
- **概览页** — 多月对比、收入支出双线图、本月/上月差异
- **日历视图** — 月历方格按天显示净值,点击进交易明细
- **年度报告** — 12 屏沉浸式回顾,生成可分享的海报(适合年终复盘 + 朋友圈分享)
- **分析页** — 跨月趋势 + 分类深度分析

所有数据跟手机端共用同一份云端账本,分析口径完全一致。
