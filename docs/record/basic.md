# 基础记账

蜜蜂记账支持三种交易类型：支出、收入和转账。

## 快速记账

点击底部中央的 **「+」按钮** 进入记账页面。

![记账页面](/img/preview/v4/zh/light/05-transaction.png)

### 操作步骤

1. **选择类型** - 支出 / 收入 / 转账
2. **输入金额** - 使用数字键盘输入
3. **选择分类** - 点击分类图标；有子分类时先展开，再选择末级分类
4. **选择账户** - 选择关联账户
5. **保存** - 点击数字键盘下方的「保存」

> **App 4.0**：数字键盘固定在底部，分类区域使用剩余空间；二级分类默认四列，较长名称可占两格。键盘支持加减乘除，可以直接计算分摊或合并金额。

### 连续记账

新建支出或收入时，点击「再记一笔」保存当前记录并继续填写下一笔；只记一笔时点击「保存」返回明细。

### 可选信息

- **备注** - 在表单中直接输入和修改交易说明
- **标签** - 打上一个或多个标签
- **日期时间** - 修改记账时间（补记）
- **图片** - 添加消费凭证

## 复制交易

从 **App 3.8.6** 起，首页明细支持长按复制：

1. 长按要复用的支出、收入或转账，选择「复制」。
2. 金额、分类、账户、备注、标签、币种和统计/预算标记自动带入；日期时间默认为当前时间，可以修改。
3. 调整需要变更的内容，点击「完成」，保存为独立的新交易。

原交易保持不变，取消编辑不会创建记录。原交易的图片附件不会复制，需要为新交易重新添加凭证。

## 交易小票

从 **App 3.9.0** 起，可以把一笔交易生成为可保存或分享的小票图片：

1. 长按首页明细中的支出、收入或转账，选择「生成小票」。
2. 在预览中选择是否展示备注、标签、账户和账本；账户与账本默认不展示。
3. 选择保存到相册，或通过系统分享菜单发送图片。

生成小票不会创建或修改交易。原始消费凭证可保存为[交易附件](./attachment.md)。

## 编辑与删除

- **点击** 交易记录可编辑
- **左滑** 交易记录可删除

## 转账记录

转账用于在不同账户间转移资金：

- 选择「转账」类型
- 选择转出账户和转入账户
- 输入转账金额

App 4.0 将账户选择与金额输入放在同一页面。新建转账只允许同币种账户之间互转；选择外币账户对时，可查看按当前账本本位币折算的金额，缺少汇率时先补齐汇率。

系统会自动更新两个账户的余额。

## Web 端记账

登录 [BeeCount Cloud](../cloud-sync/beecount-cloud.md) Web 端后,桌面浏览器记账更高效:

- **+ 新建交易按钮** — 交易页右上角点击,弹窗填字段保存
- **⌘K / Ctrl+K 命令面板** — 任意页面按快捷键 → 输入金额或备注 → 选「新建交易」直接记
- **批量操作** — 列表页支持多选删除 / 导出 CSV(详见[交易管理](../features/record.md))
- **桌面端键盘体验** — 数字键盘、Tab 切换字段、Enter 保存

Web 端创建的交易通过云同步秒级推到手机,反之亦然。
