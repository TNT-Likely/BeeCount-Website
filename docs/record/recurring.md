# 周期记账

自动记录固定收支，适合工资、房租、订阅等周期性交易。

## 创建周期账单

1. 进入「我的」→「自动化」→「周期账单」
2. 点击「+」创建
3. 填写交易信息
4. 设置周期和执行时间

## 周期类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 每日 | 每天执行 | 日常通勤 |
| 每周 | 每周固定日 | 周末娱乐 |
| 每月 | 每月固定日 | 工资、房租 |
| 每年 | 每年固定日 | 年费会员 |

## 币种(v3.7.2)

创建周期账单时可以**选择币种**,不再只能记账本主币种:

- 选了账户就跟随账户币种;没选账户时用你在模板上选的币种
- 改币种会按新币种重新过滤账户候选,已选账户会被清空、需要重选
- 每次生成账单**按当日汇率折算**——「每月 10 美元」不会被写死成某个固定的人民币金额
- 列表里外币模板会在金额前标出 ISO 币种码

存量周期账单没有币种即代表账本主币种,行为与升级前完全一致。详见[多币种](../account/multi-currency.md)。

## 常见场景

- **工资** - 每月固定日期收入
- **房租/房贷** - 每月固定支出
- **订阅服务** - 视频/音乐会员
- **话费** - 每月固定扣费
- **保险** - 年度保费

## 管理周期账单

- **暂停** - 临时停止执行
- **恢复** - 重新启用
- **删除** - 完全移除
- **设置期限** - 指定开始和结束日期
