# 交易附件

为交易添加图片附件，用于保存消费凭证、发票等图片资料。

## 添加附件

### 记账时添加

1. 在记账页面，点击底部的「附件」图标
2. 选择「拍照」或「从相册选择」
3. 图片会自动添加为附件
4. 完成记账后，附件随交易一起保存

### 编辑时添加

1. 打开已有交易的详情页
2. 点击「编辑」
3. 在附件区域添加图片
4. 保存修改

## 查看附件

- 在交易列表中，有附件的交易会显示附件图标
- 点击交易进入详情页，可以查看所有附件
- 点击附件图片可放大查看

## 删除附件

1. 进入交易编辑页面
2. 长按要删除的附件图片
3. 确认删除

## 自动保存附件

在「我的」→「智能记账」开启「自动添加附件」后，使用以下方式记账时，图片会自动保存为附件：

- **图片记账** - 选取的图片自动保存
- **拍照记账** - 拍摄的照片自动保存

## 附件保存原图

从 **3.8.4** 起，可在「我的」→「智能记账」→「自动添加附件」下方开启「附件保存原图」。开关默认关闭，保持原有压缩方式，修改后即时生效，无需重启。

- 开启后，手动添加附件、图片记账和拍照记账保留传入图片的原始尺寸与画质；iOS 快捷指令截图记账也遵循该设置。
- AI 识别使用单独的压缩副本，最长边不超过 1920 像素；保存的原图附件不受识别副本影响。
- 自动保存仍需开启「自动添加附件」；手动添加附件也可以保存原图。
- 原图会占用更多存储空间和同步流量。

:::tip 已有附件
开关只影响之后新增的附件。已压缩的图片不会自动恢复画质，需要从原图重新添加。
:::

## 附件导出

附件可以单独打包导出：

1. 进入「我的」→「数据管理」→「导出附件」
2. 在预览中查看附件和自定义图标
3. 确认后导出压缩包

从 **3.8.4** 起，导入和导出预览的缩略图及放大详情会显示实际文件大小与宽 × 高，方便核对图片是否保留原始尺寸。

## 注意事项

- 附件存储在本地，会占用设备存储空间
- 云同步时，附件也会同步（取决于云存储方案）
- 建议定期清理不需要的附件

## Web 端附件

登录 [BeeCount Cloud](../cloud-sync/beecount-cloud.md) Web 端后:

从 **Cloud 1.7.0** 起，可在新建和编辑交易时管理图片附件：

1. 在交易页面点击「新建交易」，或打开已有交易并进入编辑。
2. 在附件区域选择图片。编辑时可以移除已有图片，再添加替换图片。
3. 点击「保存」，附件变更才会关联到交易；取消编辑保留交易原有的附件关联。

Web 上传保留文件原始字节，可放大查看和下载原图。附件随交易与 App 双向同步；建议先升级 Cloud，再升级 **App 3.8.6**，确保已有附件的顺序和信息变更也能同步。

- **AI 截图记账自动绑定附件** — ⌘K 粘贴图片做 AI 记账时,N 笔交易**自动共享**这一张原图作为附件;详见 [AI 图片识别](../ai/image.md#web-端图片记账)
- **交易行 📎 chip** — 列表里有附件的交易显示附件图标,点击调出 attachment carousel(支持上下张切换)
- **交易详情查看附件** — 点击交易行打开 detail dialog,附件区可放大查看 / 下载
- **附件存储** — Web 端附件存在 BeeCount Cloud server 的 `attachment_storage_dir`,跟手机端通过 sha256 dedup 共享,跨设备一份不重传
