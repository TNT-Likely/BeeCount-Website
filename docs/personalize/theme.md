# 主题色设置

蜜蜂记账支持自定义主题色，打造个性化界面。

![个性化设置](/img/preview/zh/10-personalization.png)

## 修改主题色

1. 进入「我的」→「个性化设置」
2. 点击「主题色」
3. 选择预设颜色或自定义

## 预设颜色

- 🟡 **蜜蜂黄** - 默认主题色
- 🔵 **天空蓝**
- 🟢 **森林绿**
- 🟣 **优雅紫**
- 🔴 **热情红**
- 🟠 **活力橙**

## 自定义颜色

点击调色板图标，可以选择任意颜色作为主题色。

## 主题色应用

主题色会应用到：

- 导航栏
- 按钮
- 选中状态
- 图标强调色
- 图表配色

## 皮肤

> ✨ **v3.3.0 新增**

「个性化设置」里新增**皮肤**:首页顶部的装饰图案,自动跟随你的主题色,亮色/暗色模式通用。

- 内置渐变、场景、几何等多款风格,按系列分组
- 多设备自动同步
- 支持配置导入导出,可以把自己的搭配分享给别人

### 动态皮肤

> ✨ **v3.7.1 新增**

**一岁星座**与**周年蛋糕**是 BeeCount 的首批动态皮肤,为纪念首版发布一周年推出,在皮肤选择页置顶并带「1st」角标:

- **一岁星座** — 十颗星连成数字「1」,一只发光小蜜蜂拖着彗尾绕它巡航,外加银河带、星云、月牙与流星
- **周年蛋糕** — 插着数字「1」蜡烛的蛋糕,烛火摇曳、糖粒升起

部分皮肤**自带配色**(如周年蛋糕的奶油金),选中后 App 主题色会跟着切过去,换回普通皮肤时自动恢复你原先手选的颜色 —— 避免出现「头部一个色、按钮另一个色」的割裂。选择页上这类皮肤带「自带配色」标记,预览即按它自己的颜色渲染。

### 皮肤动效开关

> ✨ **v3.7.1 新增**

「个性化设置」→ **皮肤动效**。关闭后动态皮肤停在静止画面 —— 那一帧是按构图最完整的时刻挑的,静态版本身也好看 —— 同时更省电。

系统的「减弱动态效果」无障碍设置优先级更高:开启后不论 App 里这个开关是什么,动效都会停下。

## 字体大小

支持调整应用字体大小：

- 小
- 标准（默认）
- 大
- 超大

适合不同视力需求的用户。

## Web 端主题色

登录 [BeeCount Cloud](../cloud-sync/beecount-cloud.md) Web 端 → 头像菜单 → **个人资料** → 顶部「主题色」chip:

- 弹出 PrimaryColorPicker,跟手机端同款 20 色调色板(深橙 / 粉红 / 紫色 / 蓝色 / 绿色...)
- **Web 本地优先** — 改完只存当前浏览器 localStorage,不会推回手机
- **手机端反向同步** — 手机改主题色会自动下发到 Web;但本地改过后以本地为准,手机后续变更不覆盖
