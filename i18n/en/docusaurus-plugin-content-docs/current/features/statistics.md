# Statistics & Analysis

BeeCount provides rich statistical charts to help you understand your financial situation.

![Statistics Page](/img/preview/v4/en/light/02-analytics.png)

## Income & Expense Trends

App 4.0 uses tabs for expense, income and balance views. The trend bar chart includes an average line; tap a bar to inspect its day or month.

## Category Breakdown

A separate card shows category proportions and rankings using the theme accent. The balance view shows the income/expense composition.

## Category Ranking

A list view shows categories ranked by amount. Tap to view all transactions in that category.

## Time Filter

Use the Month / Year / All tabs, then the date control to select a specific period.

## Home Summary Layout

The home page defaults to the full summary. Open its top-right More menu and choose the compact summary to combine the budget indicator with income and expenses in one card. Switch back to the full summary from the same menu; the preference is saved.

## Web Statistics

After signing in to [BeeCount Cloud](../cloud-sync/beecount-cloud.md) on the web, the desktop browser unlocks richer visualizations:

- **Home hero** — current-month summary + income/expense curve + asset composition donut + top categories / tags / accounts
- **Overview page** — multi-month comparison, dual-line income/expense, MoM diff
- **Calendar view** — month-grid by day with net values; click a cell to see transactions
- **Annual report** — 12-screen immersive recap, shareable poster (great for year-end review)
- **Analytics page** — cross-month trends + deep category analysis

All data shares the same cloud ledger as mobile, so the analytics figures match exactly.
